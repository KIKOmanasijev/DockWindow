      A Dock per desktop

      Each desktop gets a Dock with just its apps.

      Keep work on one desktop and personal stuff on another. When you swipe between them, the Dock changes too, so it only shows what’s open where you are. Your pinned apps stay on every Dock.

      Rather see everything? Settings can show windows from all desktops instead.

      Window switching, done right

      Switch to any window, not just any app.

      On a Mac, Cmd+Tab shows one icon per app, so two Safari windows look like one. DogBar gives every window its own tile, with its name and a preview, so you land on the exact one you want.

      A Dock you already know

      Feels like the Mac Dock, with the parts it’s missing.

      Pinned apps, a divider and running dots sit where you expect them. DogBar adds window previews, a dot for every open window and a Dock for each desktop.

      Hover the Dock to preview windows.

      Hover any app to see all its windows. Click the one you want and only that window comes up. You can close or minimize it right from the preview.

      See how many windows each app has.

      Each app gets one dot per open window. Want a bigger Dock? Drag its edge. Icons stay still, with no magnifying.

      Get a separate Dock on every desktop.

      Rather keep Apple’s Dock?

      Turn on Native Dock mode. Apple’s Dock stays, and you still get window previews and better window switching. A Dock per desktop and window dots need DogBar’s own Dock. Pause DogBar anytime and it puts your old Dock and its settings back.

      You can also choose whether the Dock, window switcher and previews show windows from this desktop or from all of them.

      Questions about DogBar

      What is DogBar?

      DogBar is a native macOS window switcher and Dock app. It shows a preview for each open window, lets you choose a window from the Dock, and can give each desktop its own Dock.

      Which Macs can run DogBar?

      The current preview requires an Apple Silicon Mac running macOS 14 or later. It is self-signed and not notarized by Apple.

      Do I have to replace Apple’s Dock?

      No. Native Dock mode keeps Apple’s Dock and still adds window previews and better window switching.

      Why does DogBar need Accessibility and Screen Recording?

      Accessibility lets it bring up, close and minimize single windows, and listen for its shortcut. Screen Recording lets it show what’s inside each window in the previews.

      How do I get my normal Dock back?

      Click the paw in the menu bar and choose Pause DogBar or Restore Native Dock. Either one brings your old Dock back.

      How do I switch windows with DogBar?

      Press the switcher shortcut and keep holding its modifier key. Tap again to move on, add Shift to go back, or use the arrow keys. Let go to switch, or press Escape to cancel.

      Can I change the window switching shortcut?

      Yes. It’s Option+Tab by default. Record a different one in Settings → Switcher. You can also have the switcher show apps instead of windows, or turn it off and keep Apple’s Cmd+Tab.
