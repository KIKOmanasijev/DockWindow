      Built for Macs with a lot of windows open.

      01

      Alt+Tab, finally on the Mac.

      Cmd+Tab shows one icon per app, even when that app has five windows open. DogBar’s Option+Tab shows every single window as its own tile, just like on Windows. Hold Option, tap Tab, let go, and you’re in the exact window you wanted.

      02

      Every desktop is its own workspace.

      Each desktop gets a Dock with only the apps you use there, so work stays with work and personal stays personal. Click Safari when its windows live on another desktop, and DogBar asks for a new window right here instead of pulling you away. Pinned apps show up everywhere.

      03

      See a window before you switch to it.

      Hover any app in the Dock to see a preview of each of its windows. No more guessing which Safari window is which. Click the one you want and exactly that window comes forward, or close, minimize or zoom it with its traffic lights.

      04

      Know how many windows are open.

      Like the Windows taskbar, each app shows one dot for every open window. Three dots, three windows. Drag the Dock’s edge to make it bigger or smaller, and the icons stay put with no magnification wobble.

      Set it your way.

      Show apps and windows from the current desktop or from all desktops, set separately for the Dock, the switcher and previews.

      Rather keep Apple’s Dock? Native Dock mode still gives you previews and the switcher. Pause brings the regular Dock back anytime.
