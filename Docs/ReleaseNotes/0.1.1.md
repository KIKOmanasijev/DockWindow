# DogBar 0.1.1

- New guided onboarding with an animated mascot, product demos and clear permission steps.
- Improved first-install Screen Recording guidance, including installing into Applications and reopening after granting access.
- Added signed in-app updates with Sparkle and configurable automatic update checks.
- Fixed the New Window preview's hover state and matched its height to window previews.
- Improved desktop identification when switching Spaces.
- Paused DogBar's Dock, previews and switcher throughout onboarding, including replayed tours, to avoid overlapping Docks.

Requires Apple Silicon and macOS 26 or later.

## Installing this update

DogBar 0.1.0 and public previews through preview 5 do not include Sparkle. Install 0.1.1 manually once: quit DogBar, drag the new app into Applications, replace the existing copy, eject the disk image and reopen DogBar. Later versions can update through **Check for Updates…**.

If macOS asks again for Accessibility or Screen Recording, enable DogBar and choose Quit & Reopen. Existing settings are retained.
