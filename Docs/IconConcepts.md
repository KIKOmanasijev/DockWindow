# Cartoon icon concepts

Created with the built-in image generation tool. The tool does not expose a model selector. Current official OpenAI documentation recommends GPT Image 2.5 Flare for fast high-quality generation and Sunburst for precise editing. Flare is the recommended model for concept exploration; this is a workflow choice, not a cross-provider benchmark. Source: https://developers.openai.com/api/docs/guides/image-generation

PNG assets: Resources/IconConcepts/dog-windows.png and cat-windows.png. Both are original mascot/window compositions guided by the user's pet icon reference. The user selected the fluffy dog with stacked windows. Resources/AppIcon.icns packages that concept at the standard macOS icon sizes.
